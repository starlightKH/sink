# Laftel Sync

웨일/크롬 브라우저에서 라프텔 영상 재생을 서로 동기화할 수 있는 확장 프로그램과 간단한 WebSocket 중계 서버입니다.

## 구성 요소

- `extension/` – 웨일/크롬 확장 프로그램 소스
- `sync-server/` – Node.js 기반 WebSocket 중계 서버

## 사용 방법

1. **서버 실행**
   ```bash
   cd sync-server
   npm install
   npm start
   ```
   기본적으로 `ws://localhost:8080`에서 대기합니다. 필요에 따라 포트를 변경하려면 `PORT` 환경 변수를 지정하세요.

2. **확장 프로그램 설치**
   1. 크롬 또는 웨일 브라우저에서 `chrome://extensions` (웨일은 `whale://extensions`) 페이지를 엽니다.
   2. 우측 상단에서 "개발자 모드"를 활성화합니다.
   3. "압축해제된 확장 프로그램을 로드" 버튼을 클릭하고 `extension/` 디렉터리를 선택합니다.

3. **연결 설정**
   - 확장 프로그램 아이콘을 클릭하여 팝업을 열고, 서버 URL (`ws://localhost:8080`)과 동기화에 사용할 룸 ID를 입력한 뒤 **연결**을 누릅니다.
   - 동일한 서버 URL과 룸 ID를 다른 PC에서도 입력하면 재생/일시정지/이동/배속 변경이 서로 동기화됩니다.

## 동작 방식

- 콘텐츠 스크립트가 라프텔 페이지의 `<video>` 요소 이벤트를 감지해 백그라운드 서비스 워커로 전달합니다.
- 백그라운드 서비스 워커는 WebSocket을 통해 서버에 이벤트를 전송하며, 서버는 동일한 룸에 연결된 다른 클라이언트들에게 이벤트를 브로드캐스트합니다.
- 원격 이벤트를 수신하면 해당 브라우저의 영상에 동일한 동작을 적용합니다.

## 주의 사항

- 확장 프로그램이 동작하려면 팝업에서 서버 연결을 먼저 설정해야 합니다.
- 브라우저 자동 재생 정책 때문에 원격 재생 요청이 차단될 수 있으며, 이 경우 사용자 입력 후 동기화를 다시 시도하면 정상 동작합니다.
- 본 예시는 학습용으로 제공되며, 실제 서비스에서는 인증, 오류 처리, 연결 복구 등을 추가 구현하는 것이 좋습니다.
